# Sontradex s.r.o. – Webové stránky

**sontradex.com** – Ekologický výkup kazet a výpočetní techniky. Est. 2001.

## Stack
- Čistý HTML5 + CSS3 (bez závislostí, žádný build step)
- Fonty: Google Fonts – Inter
- Deployment: Vercel nebo GitHub Pages

## Lokální vývoj

```bash
# Jednoduše otevři index.html v prohlížeči, nebo použij live server:
npx serve .
```

## Deploy na Vercel

1. Forknout / pushni repozitář na GitHub
2. Přejdi na [vercel.com](https://vercel.com) → **New Project**
3. Importuj repozitář
4. Framework Preset: **Other** (statický web)
5. Klikni **Deploy** ✅

> `vercel.json` je již připravený v projektu.

## Deploy na GitHub Pages

1. Přejdi do Settings → Pages
2. Source: **Deploy from a branch → main → / (root)**
3. Klikni Save ✅

## Struktura

