Tento repozitář obsahuje zdrojové kódy pro webové stránky společnosti **Sontradex s.r.o.** (Est. 2001). Projekt slouží jako moderní vizitka firmy a platforma pro výkup použité IT techniky.

🌍 **Live verze:** [sontradex.com](https://sontradex.com)

---

## 🏢 O projektu

Sontradex s.r.o. se více než dvě dekády věnuje odkupu, recyklaci a vracení IT techniky zpět do oběhu. Náš web má za cíl edukovat a usnadnit firmám i jednotlivcům ekologickou likvidaci elektroniky.

**Klíčové pilíře:**
* 🏛️ **Heritage (Est. 2001):** Dlouholetá tradice, stabilita a spolehlivost na českém trhu.
* ♻️ **Cirkulární ekonomika:** Dáváme hardwaru druhou šanci (closed-loop systém).
* 🌱 **Ekologie:** Zabraňujeme tomu, aby toxické materiály z tonerů a počítačů končily na skládkách.
